# Kingdom Rush Origins 关卡加速 Mod

版本 1.2.0，目标：Windows Steam build 24662341 / 游戏 6.4.46。

1.2.0 新增 3×、5× 和 R 恢复原速；人物语音保持原速、原音调。沿用 1.1.1 的音源生命周期修复，避免暂停退出或通关返回地图时访问已释放的音源。升级时运行新版安装包中的安装器即可。

## 操作

进入关卡或重试后从 **1×** 开始，暂停后继续保留倍率。

| 按键 | 循环顺序 |
| --- | --- |
| **Q** | 5× → 3× → 2× → 1.5× → 1× → 5× |
| **E** | 1× → 1.5× → 2× → 3× → 5× → 1× |
| **R** | 任意档立即回到 1× |

长按只切换一次。松开再按才切换。K／L 不再由 Mod 处理。

倍率牌位于左下角第三个技能按钮（英雄技能）的右边，使用游戏自带画框与 HUD 字体，提示 Q／E 和 R。**仅用于显示，没有点击或悬停反馈，也不拦截鼠标。** Q／E／R 专用于关卡变速，不转发给其他游戏快捷操作；组合键和其他按键仍由游戏处理。

**请使用英文输入状态操作 Q／E／R。** 快捷键只在关卡正常操作且窗口具有焦点时生效，暂停菜单、通知和结算优先处理输入。

## 安装和卸载

关闭游戏，双击 `install.cmd`。正常从 Steam 启动即可。升级本 Mod 也运行同一安装器；已被手动修改的模块不会被直接覆盖。

卸载：关闭游戏，双击 `uninstall.cmd`。

默认安装位置：`%APPDATA%\kingdom_rush_origins`。只有以下内容会被添加或调整：

- `kro_speed_mod.lua`：独立模块。
- `settings.lua`：添加 `custom_script = "kro_speed_mod"` 加载入口；保留现有设置。
- `.kro_speed_mod/manifest.json` 和 `backups/`：安装记录及受影响配置的备份。

不修改游戏安装目录、EXE、DLL、原脚本或资源包；无需注入器、常驻程序或附加音频组件。运行时直接引用已经加载的游戏美术素材，不打包或复制原版素材。Steam 完整性检查不会因为本 Mod 在安装目录产生差异。

如果已有其他 `custom_script`，安装器会拒绝覆盖并报告冲突。卸载只移除仍指向本模块的配置与确认属于本次安装的模块，不整份恢复旧设置，不触碰存档。配置备份会保留，可在确认不再需要后自行删除 `.kro_speed_mod` 文件夹。

游戏更新后，模块核查版本与必要接口，不支持时停用。停用不等于承诺兼容未来版本；请查测试记录后再更新 Mod。

## 模拟与声音

1× 直接调用原版模拟；1.5×、2×、3× 和 5× 将时间拆成不大于原版模拟步长的小步，保持原系统执行顺序。移动、攻击、弹道、波次等使用同一个模拟时钟。

**人物语音保持原速、原音调**，包括英雄和防御塔台词、NPC 语音；语音播放延迟和重复抑制也使用原时间。按音源类别和具体 ID 区分混合分组中的语音与技能音效；原版已将人声和效果混在同一录音中的声音，整段保持原速，以保留人声。

其余战斗、环境音效仍随倍率加速并升调；音乐和 UI 声音保持原速。切换倍率只调整音源 pitch，不重启播放；R 立即恢复 1× 与原始音源参数，退出关卡时同样恢复。

原版在低渲染帧率或卡顿时可能丢失模拟步。为满足“1× 与原版一致”，1× 保留原行为；不能将低帧率下受影响的原版实测耗时当作精准倍速的基准。
